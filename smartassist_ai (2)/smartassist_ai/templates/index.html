About the project

What SmartAssist AI actually does

An intelligent customer service chatbot and support management system built for the MCA project synopsis at Karnataka State Open University — demonstrating how classic, interpretable machine learning can automate real customer support workloads without heavy infrastructure.

🎯

Problem it solves

Manual triage of routine queries is slow and inconsistent. Rigid keyword filters break on typos and phrasing. SmartAssist AI replaces both with a trained classifier, a rule-based priority engine, and a self-improving correction loop.

🧠

How it thinks

Every message is cleaned, vectorized with TF-IDF (unigrams + bigrams), and classified by a Multinomial Naive Bayes model — and when an admin corrects a misclassification, that correction is folded straight back into retraining.

🚦

How it prioritizes

A transparent points-based scorer combines ML confidence, detected sentiment, and critical keywords to assign urgency, auto-assign the right agent, and auto-escalate when needed.

💸

Beyond support tickets

A personal expenditure tracker learns each user's spending patterns — by category and by time of day — and surfaces personalized, automated recommendations plus printable monthly/yearly invoices.

🔔

Always in the loop

A notification center keeps users updated the moment a ticket is escalated, resolved, or a transaction completes — no need to keep refreshing.

🗂️

Nothing lost by accident

Deleted expenses go to a Recycle Bin, not straight to the void — restore them any time before they're gone for good.

Project objectives

1

Classify incoming queries into Billing, Technical Support, Account Issues, Order Tracking, and General FAQ.

2

Score urgency (Critical / High / Normal / Low) and auto-assign the right agent from confidence and sentiment.

3

Run real-time sentiment analysis to catch dissatisfied customers early, with 👍/👎 feedback on every reply.

4

Auto-escalate low-confidence or critical interactions, and notify the user the moment it happens.

5

Give every user a personal space: profile, login history, incidents, expenditure tracker with invoices & recycle bin.

6

Let admins correct misclassifications and retrain the model on its own mistakes — a continuously smarter system.

7

Expose REST API endpoints for programmatic classification, analytics, and account management.
